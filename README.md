# Fala Doutor

Projeto simples para gerenciamento de médicos e pacientes.

## Instalação
Baixar o pgAdmin e criar um banco de dados com o nome fala_doutor

No arquivo .env preencher os valores corretos para a conexão com o banco

Entrar nas pastas do backend e frontend e rodar o comando abaixo em ambas

```bash
npm install
```

## Como rodar

Entrar nas pastas do backend e frontend e rodar o comando abaixo em ambas

```bash
npm run dev
```
